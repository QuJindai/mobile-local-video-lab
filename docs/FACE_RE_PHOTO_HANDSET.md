# FACE-RE V0.9.0 手机测试范围

包名仍为 `com.qujindai.localvideo`，版本 `0.9.0` / code `11`，沿用原签名。
安装后应用名显示 FACE-RE，首页进入照片换脸；“视频实验”可进入原工作台。

## 使用

1. 点击“准备换脸模型”。首次下载三个模型，共 732,986,691 字节（约 699 MiB）。
   下载支持断点续传，SHA-256 校验通过才激活。已下载的 MobileI2V 权重是
   另一条链路的文件，不需要重新下载。
2. 选择参考人脸和目标照片，各包含一张清晰人脸。参考照提供身份；目标照
   决定构图、姿势和背景。多人图会要求裁剪到一人。
3. 开始本机换脸；生成结束后查看结果，保存到相册并可分享。最近照片结果
   单独记录，不覆盖原视频历史。

本版接入 SCRFD 2.5G、ArcFace W600K R50 与 INSwapper 128 FP32，在 ONNX Runtime
CPU 上执行。照片最长边限制为 1600 像素以控制内存；脸部原生生成尺寸为
128×128，贴回后保持目标构图。自由提示词生成新风格／新动作以及视频换脸
仍是后续功能。

## 已取得的模型证据

GitHub Actions `34756721368`，提交 `f19b10e598ad8701e38cb9ff22dbd9c945b802dc`，
真实执行三个模型。官方测试图的参考身份与原目标余弦值为 -0.0412，与换脸
输出为 0.9331；更换身份输入后的平均像素影响为 0.03059（0–1 浮点尺度）。
这些是该测试样例的观测值，不是通用阈值或准确率。模型 host 测试单次约
2.02 秒，不代表手机耗时。
