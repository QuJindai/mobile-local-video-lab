## New behavior

- Depth paths: left/right parallax, push in, **arc orbit**, **crane up**, **pull back**. One local depth estimate feeds five independently warped camera keyframes. RIFE fills the intervening frames. The viewpoint changes; new subject actions, objects and scenes are not synthesized.
- Gentle / normal / strong motion; a constant crop margin for each path avoids exposing an empty source border. Stronger motion crops more. Depth boundaries can still show warping artifacts and require visual inspection on the actual image.
- 9 / 17 / 33 / 49 single-course frames. The default is arc orbit, normal strength, 33 frames, 8 FPS (4.125 seconds). Optional forward/backward looping references the existing frame files and omits duplicated turning frames: 33 source frames produce 64 output frames / 8 seconds at 8 FPS.
- RIFE's original directory sampler repeated the final input for much of the output. The pinned source is patched to spread interpolation across the entire timeline, affecting both two-image RIFE and five-keyframe Depth.
- Duration preview, remembered motion controls, and recipes in new result/history entries. Existing seven-field result records and older URI history remain readable.
- Model download/device details collapse by default. Selecting MobileI2V opens them. Backend-specific labels are hidden with their controls; system bar insets protect the main screen.

## MobileI2V status

The full model package is **not qualified or included**. The denoiser precision comparisons remain failed; see `MOBILEI2V_PRECISION_DIAGNOSIS.md`. Original checkpoint download, SHA-256 verification, model pack import and the MNN OpenCL execution path are retained. The new motion/loop controls do not apply to MobileI2V, whose output remains fixed at 17 frames. Native library loading does not establish GPU model inference.

## One handset pass

Install over the prior lab version. Start with **Depth 3D → arc orbit → gentle → 33 frames → 8 FPS → forward/backward loop**. The expected file is 64 frames, about 8 seconds, saved to `Movies/LocalVideoLab`. Check the midpoint reversal, absence of a long frozen ending, fullscreen playback and system sharing. One generated MP4 plus exported diagnostics provides useful feedback.

Build, host sequence tests and signature verification do not substitute for handset rendering, Samsung codec, motion-quality or thermal measurements. No airplane mode is required.
