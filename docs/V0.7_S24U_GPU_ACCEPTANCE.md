## What the build checks

Deterministic pack tests, generation-source guard regressions, JVM unit tests,
Depth Anything Q4 hash and host inference, MNN/OpenCL and RIFE/Vulkan native
builds, packaged runtime/model presence, arm64 ELF alignment of at least 16 KB,
APK version, launcher and the stable development certificate.

These checks prove packaging and tested host behavior only. They do not prove
installation, video quality, thermal performance or GPU execution on S24U.

## Remaining MobileI2V prerequisite

The APK contains the runtime, not the converted MobileI2V model weights. A real
v2 GPU `.mlvpkg` with denoiser, VAE encoder/decoder and conditioning artifacts
must be exported and pass parity validation before MobileI2V handset acceptance.
The upstream `.pth` download is not that pack. No validated GPU pack or complete
export pipeline is supplied by this candidate; no successful MobileI2V handset
run is claimed.

## One integrated handset run

1. Install the candidate as an update and check version and retained results.
2. Generate a RIFE clip and a Depth 3D clip; play, save and share the MP4s.
3. Without a GPU pack, select MobileI2V and confirm it reports the missing pack.
   It must not claim success or silently generate using RIFE.
4. Only after the validated GPU pack is available: import it, select MobileI2V,
   generate 17 frames, and play/save/share the resulting MP4.
5. Export diagnostics and retain the output video. Model identity, actual
   denoiser/VAE backend evidence, time, memory and thermal data must be checked
   together; hard-coded backend labels alone do not establish GPU execution.

Airplane-mode testing is not part of this acceptance run or its release gate.
Keep PR #4 as a draft until real model parity and handset acceptance are complete.
