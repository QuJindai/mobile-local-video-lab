# V0.7.1 手机测试版

本版供用户覆盖安装并在 S24U 上测试。不是 MobileI2V 出片完成版。

- applicationId：`com.qujindai.localvideo`
- versionName：`0.7.1`；versionCode：`8`
- Android 9+，仅 `arm64-v8a`
- 保持 V0.2+ 实验室签名，证书 SHA-256：
  `c9329387060f0259870e30b7bca6b9d9684ed86de716676962a1e75ef7f346ac`

## 本轮修复

MobileI2V Android 接口改为已确认的四输入主模型，删除旧的文本输入依赖；
VAE 编码器增加显式随机噪声输入。新版模型包必须声明
`io.contract=mobilei2v-ltx-explicit-noise-v1`，不兼容旧接口的包会被拒绝。
原生张量传输检查实际类型、形状、大小和有限值，拒绝当前 MNN 版本不能
安全处理的半精度端口。请求 OpenCL 高精度，并检查实际执行后端。

诊断导出在启动后即可使用，包含版本、设备、模型包、原生库加载、生成门槛
以及最近一次任务结果。原有 RIFE、Depth 3D、历史结果、播放和分享保留。

## 当前限制

VAE 编码器和解码器只通过了主机验证，主模型数值精度尚未通过；完整的
MobileI2V GPU 模型包尚未提供。本 APK 不包含 MobileI2V 模型权重，也不
宣称已经在 Adreno 上运行成功。下载原始 `.pth` 不能启用 MobileI2V。
RIFE/Depth 3D 的运动能力没有因本轮接口修复变成语义视频生成。

## 一次本机测试

1. 覆盖安装，确认显示 V0.7.1 且历史结果仍在。若系统报签名冲突，保留
   现有应用和数据，反馈错误；无需卸载。
2. 同一张主图分别生成 RIFE 和 Depth 3D 视频，检查播放、保存和分享。
3. 切换 MobileI2V，确认显示缺少兼容模型包并阻止生成。
4. 点击“导出诊断信息”，连同结果视频或报错截图一次发回。

无需飞行模式测试。手机实际安装、耗时、热状态和视频效果由这次本机测试
确认；CI 的编译、测试与包签名核验不替代这些结果。
