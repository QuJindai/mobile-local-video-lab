# V0.4 Model Backend Milestone

V0.3 is the handset-validated RIFE/ncnn/Vulkan baseline. V0.4 changes the app architecture so a real semantic image-to-video backend can be installed without replacing the UI or export pipeline.

## Scope

1. Introduce an explicit backend catalog and routing policy.
   - `rife-motion`: built-in, always available when the packaged RIFE runtime is valid.
   - `mobilei2v`: semantic I2V candidate, activated only when a valid model pack and compatible runtime are present.
2. Add a versioned external model-pack format (`local-video-model-pack-v1`).
   - streaming ZIP install; no whole-model buffering in Java heap;
   - path-traversal rejection;
   - manifest schema validation;
   - per-artifact SHA-256 verification;
   - atomic activation/rollback;
   - model packs live in app-private storage and are removable independently of the APK.
3. Add a device-capability snapshot for backend decisions.
   - ABI/API/SoC;
   - total RAM and Java heap;
   - OS page size;
   - Vulkan feature availability;
   - app-private free storage.
4. Add a Model Lab section to the handset UI.
   - backend selection;
   - MobileI2V pack import/remove;
   - compatibility/readiness status;
   - model-pack size/license/source/version details;
   - RIFE remains the safe fallback.
5. Add host tooling for reproducible MobileI2V deployment preparation.
   - pin upstream source/checkpoint identities;
   - build a manifest-driven `.mlvpkg` from exported artifacts;
   - deterministic hashing and pack verification;
   - keep upstream attributions and model/code license fields separate.
6. CI gates.
   - JVM tests for manifest parsing, backend routing and pack policy;
   - host tests for pack-builder determinism and checksum verification;
   - existing Android/RIFE/16-KB/signing gates remain mandatory;
   - V0.4 APK metadata is checked explicitly.

## Non-goal / honesty boundary

V0.4 must not label RIFE motion as MobileI2V. Selecting MobileI2V is enabled only after a genuine MobileI2V-compatible runtime/model pack is present. Until that runtime lands, the UI reports `runtime pending` rather than faking semantic generation.

## Upstream basis

- HUST `hustvl/MobileI2V`: Apache-2.0 source; 0.27B architecture; public `hybrid_371.pth` checkpoint. No Android runtime implementation is published in the repository as of the V0.4 baseline.
- `VitalikDen0/Model-To-NPU` is used only as architecture research. Its PolyForm Noncommercial license means no source is copied into this repository.
